# AstraLauncher

Лаунчер Minecraft: вход по нику или через Ely.by, все версии игры, Fabric, моды, ресурспаки,
шейдеры и сборки из Modrinth, игра с другом без сервера, перенос из TLauncher,
автоматическая установка Java. Тёмная тема с красным акцентом, свой пиксельный логотип.

ТЗ, по которому он собран, лежит в [docs/PROMPT.md](docs/PROMPT.md), история изменений — в [CHANGELOG.md](CHANGELOG.md).

**Скачать:** [последняя версия](https://github.com/xiosOSP/astra-launcher/releases/latest) — файл `AstraLauncher-Portable-…exe`.
Дальше лаунчер обновляется сам.

## Как запустить готовую сборку
Скачай `AstraLauncher-Portable-0.2.0.exe` и запусти — установка не нужна.
Windows может показать окно SmartScreen («Неизвестный издатель»), потому что файл не подписан:
«Подробнее» → «Выполнить в любом случае».

При первом запуске игры лаунчер скачает файлы версии (несколько сотен МБ) и подходящую Java.
Дальше версия запускается быстро и даже без интернета.

## Нумерация версий
- `0.2.0`, `0.3.0` — большие обновления (меняется вторая цифра).
- `0.2.0 [V1]`, `0.2.0 [V2]` — небольшие. В `package.json` это `0.2.0-v1`, тег релиза — `v0.2.0-v1`.
- `1.0.0`–`1.6.0` — старая нумерация, все они старше `0.2.0`.

Релиз выпускается сам: достаточно поменять версию в `package.json` и добавить раздел
`## 0.2.0 [V1]` в CHANGELOG.md.

## Как собрать из исходников
Нужен Node.js 20 или новее.

```bash
npm install
npm start            # запуск в режиме разработки
npm run start:mock   # запуск на тестовых данных, без сети
npm run dist         # сборка для Windows: установщик + portable .exe в папке dist/
```

На Windows `npm run dist` соберёт и установщик (NSIS), и portable-версию.
На Linux/macOS установщику нужен wine, а portable собирается так: `npx electron-builder --win portable`.

## Горячие клавиши лаунчера

Команды работают **только когда активно окно AstraLauncher**. В Minecraft они не перехватываются; во время ввода ника, пути или поиска сочетания также не срабатывают.

| Сочетание | Действие |
|---|---|
| `Ctrl + 1`…`Ctrl + 6` | Главная, библиотека, моды, миры, серверы, настройки |
| `Ctrl + Enter` | Запустить выбранную игру (с обычными проверками) |
| `Ctrl + Shift + L` | Показать / скрыть журнал игры |
| `F1` | Открыть справку по горячим клавишам |

В разделе **Настройки → Горячие клавиши** можно нажать на любое сочетание и задать своё, удалить его клавишей `Backspace` или `Delete`, либо восстановить стандартные назначения. `Esc` отменяет запись. Занятые, неподдерживаемые и системные сочетания не принимаются. Справку можно также открыть кнопкой с иконкой клавиатуры в правом верхнем углу.

## Где лежат файлы
| Что | Где (Windows) |
|---|---|
| Игра: версии, библиотеки, Java, сборки | `%APPDATA%\.astralauncher` (если в пути есть кириллица — `C:\AstraLauncher`) |
| Миры, моды, скриншоты сборки | `...\instances\<версия>`, `...\instances\<версия>-fabric` или `...\instances\pack-<id>` |
| Мод для игры с другом в обычной версии | `...\friend-mods\<версия>` |
| Настройки лаунчера, общее управление | `%APPDATA%\AstraLauncher\settings.json`, `shared-options.json` |

Папку игры можно сменить в настройках.

```

  game.js        запуск через minecraft-launcher-core, состояние игры, лог
  install.js     план загрузки: Java, клиент, библиотеки, звуки, Fabric — одной очередью
  progress.js    единая шкала 0–100 % по реальным байтам, скорость и оставшееся время
  updater.js     автообновление portable-версии через релизы GitHub
  appversion.js  нумерация версий: 0.2.0, 0.2.0 [V1], сравнение со старыми 1.x
  friend.js      игра с другом через мод e4mc
  share.js       «Поделиться сборкой»: экспорт в .mrpack
  migrate.js     перенос из TLauncher / .minecraft (с чтением версии мира из level.dat)
  sharedopts.js  общее управление, мышь и звук для всех версий
  perf.js        авто-память, слабый ПК, облегчённая графика, параметры Java
  precheck.js    проверка перед запуском: диск, память, драйвер, моды
  modcheck.js    проверка модов по Modrinth: загрузчик, несовместимость, зависимости, дубли
  storage.js     место на диске и очистка лишнего
  crash.js       разбор вылетов: причина простыми словами
  worlds.js      миры и их копии (zip), автокопия после игры
  discord.js     статус в Discord через локальный канал, без библиотек
  stats.js       сколько наиграно
  modpacks.js    сборки модов Modrinth (.mrpack): установка, обновление, удаление
  servers.js     пинг серверов по протоколу Server List Ping
  accounts.js    аккаунты Ely.by: вход, обновление токена, выход
  authlib.js     authlib-injector для скинов Ely.by
  language.js    язык игры в options.txt (по умолчанию русский)
  content.js     Modrinth: поиск, установка с зависимостями, вкл/выкл модов
  java.js        Eclipse Temurin с проверкой SHA-256
  net.js         загрузки: только https, только доверенные хосты, проверка хешей
src/preload/     узкий API для интерфейса (contextBridge)
src/renderer/    интерфейс: HTML/CSS/JS без фреймворков
  js/art/        пиксельные сцены, блоки, логотип — всё рисуется кодом
  js/pages/      разделы: главная, версии, сборки, моды/ресурспаки/шейдеры, миры, скриншоты, сервера, настройки
  js/ui/tools.js окна: проверка перед запуском, игра с другом, поделиться, перенос, место на диске
dev/             тестовые данные, генератор иконки, хук сборки
```

## Безопасность
- Интерфейс изолирован: `contextIsolation`, `sandbox`, без Node.js в окне, строгий CSP.
- Всё, что приходит из интерфейса (имена файлов, версии), проверяется в main-процессе —
  удалить или открыть что-то вне папки лаунчера нельзя.
- Всё, что качает сам лаунчер, идёт только по https с серверов Mojang, Modrinth, Fabric и Adoptium
  и сверяется по хешу: клиент игры и библиотеки (SHA-1), моды (SHA-512), Java (SHA-256).
  Битый после обрыва файл перекачивается при следующем запуске.
- Звуки, текстуры и библиотеки Fabric лаунчер качает сам с официальных адресов и проверяет по хешу.
- Сборка из файла (.mrpack) может качать файлы только с Modrinth, GitHub и GitLab и только с проверкой хеша.

## Ограничения
- Вход по нику или через Ely.by. Вход через Microsoft (лицензия) не поддерживается,
  поэтому сервера с лицензионной проверкой (Hypixel и т.п.) не пустят.
- Из загрузчиков модов — только Fabric (Forge/NeoForge не поддерживаются).
- Игра с другом работает через сервис e4mc: нужна версия 1.18 или новее с поддержкой Fabric.
- Неофициальный проект, не связан с Mojang и Microsoft.
