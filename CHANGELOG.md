# Что изменилось

## 1.2.0
- **Автообновление.** Лаунчер сам проверяет новые версии на GitHub, показывает, что нового,
  скачивает обновление с проверкой SHA-256 и перезапускается в новую версию.
- **Почему игра вылетела.** После вылета появляется окно с причиной простыми словами:
  нехватка памяти, не та Java, несовместимые моды (с советами Fabric на русском),
  сломанный мод, видеодрайвер. Кнопки ведут туда, где это исправить.
- **Миры.** Новый раздел: миры каждой сборки, копия в один клик, восстановление.
  После каждой игры лаунчер сам сохраняет копию изменённых миров (хранит последние 5).
- **Несколько ников.** Нажми на ник внизу меню — переключение и добавление.
- **Статистика.** Сколько наиграно — на главной и у каждой версии.
- **Статус в Discord.** «Minecraft 1.21.4 + Fabric · В игре» с таймером.

## 1.1.0 — аудит

### Загрузка игры (по отзыву: «дёрганая» и «по каждому файлу отдельно»)
- **Одна шкала от 0 до 100 % на весь запуск.** Лаунчер сначала собирает полный список
  (Java, клиент, библиотеки, нативные файлы, Fabric, звуки и текстуры, настройки логов),
  считает общий объём в МБ и качает всё одной очередью. Раньше каждый этап начинал шкалу с нуля.
- Проценты считаются по реальным байтам и никогда не идут назад.
- Под кнопкой: «245 из 612 МБ · 8,4 МБ/с · осталось ~1 мин».
- Обновления приходят 8 раз в секунду (раньше — на каждый из ~4000 файлов).
  Заливка кнопки движется плавно, значок загрузки больше не перезапускается.
- Цифры процента моноширинные — текст не прыгает при смене 9 % → 10 %.
- Кнопка «Играть» одной ширины во всех состояниях — соседняя кнопка версии не сдвигается.
- Если всё уже скачано, вся шкала — быстрая проверка файлов, без скачка с 6 % на 100 %.
- Новый последний шаг «Запуск»: процесс игры уже стартовал, окно ещё открывается.
  Лаунчер прячется только когда окно игры действительно появилось (раньше — сразу,
  и ~10 секунд на экране не было ничего).
- 8 потоков загрузки, каждый файл — до 3 попыток при сбое связи.
- Повторный запуск без интернета больше не обращается к сети вообще.

### Исправленные ошибки
- Две установки модов одновременно портили список установленного (терялись названия)
  и качали Fabric API в один и тот же временный файл. Теперь установки идут по очереди,
  у каждой загрузки своё временное имя.
- При обновлении мода старый файл удалялся до загрузки нового — при обрыве мод пропадал.
- «Отменить запуск» обрывал и установку модов. Теперь отмена касается только игры.
- Если старый процесс игры закрывался во время нового запуска, он сбрасывал новый запуск.
- Окно «Отменить запуск?» могло закрыть уже запустившуюся игру.
- Ошибка прошлого запуска оставалась под кнопкой после смены версии.
- Просмотр скриншотов мог удалить не тот файл, если в фоне появлялся новый скриншот.
- Esc в окне «Удалить скриншот?» закрывал заодно и просмотр.
- Ошибка удаления скриншота ничего не показывала.
- Нельзя было выключить мод в одной сборке, пока запущена другая.
- «Ускорить игру» писала «Готово», даже если зависимость не поставилась.
- Размер окна в настройках не обновлялся, если лаунчер его поправил (100 → 640).
- Компьютер с 8 ГБ показывался как «7 ГБ».
- Если игра падала до открытия окна, пользователь не видел никакой ошибки.

### Улучшения
- Логи старых версий (1.7–1.16) были в XML — теперь обычные строки «[main/INFO]: …».
- Настройки логов берутся из официального JSON версии (с исправлением Log4Shell) для всех версий.
- После отмены запуска под кнопкой пишется, что скачанное сохранилось.
- Своя подсказка для каждого варианта «После запуска игры».
- Кнопка версии во время загрузки выглядит неактивной.
- На больших мониторах контент занимает всю ширину, без пустой полосы слева.
- Тексты: «Установить с Fabric» вместо «С Fabric», «Установлен» везде одинаково, «тыс.».
- Доступность: диалоги подписаны заголовком, фокус не уходит из просмотра скриншотов
  и возвращается на миниатюру после закрытия.
