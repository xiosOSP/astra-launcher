# AstraLauncher — ТЗ (промпт, по которому собран лаунчер)

## Задача
Настольный лаунчер Minecraft для Windows (работает и на Linux/macOS) по эскизу:
тёмная тема, красный «адский» акцент, левое меню, большой баннер с кнопкой «Играть».
Правую колонку эскиза (серверы, новости, друзья) не делаем.

## Что должен уметь
1. **Вход по нику** (офлайн). Ник 3–16 символов: латиница, цифры, `_`.
   UUID считается так же, как в ванильном офлайн-режиме (`OfflinePlayer:<ник>` → MD5 v3),
   чтобы инвентарь в мирах не терялся между запусками.
2. **Версии**: полный список из официального манифеста Mojang, фильтры
   «Релизы / Снапшоты / Старые», поиск, отметка «Установлена», удаление.
3. **Загрузчик Fabric** для любой версии, которую поддерживает Fabric.
   Профиль = версия + загрузчик (`1.21.4` или `1.21.4 + Fabric`).
4. **Java ставится сама**: лаунчер читает из JSON версии, какая Java нужна (8/17/21/…),
   и качает JRE Eclipse Temurin (Adoptium) с проверкой SHA-256. Можно указать свою Java.
5. **Моды и ресурспаки** из Modrinth: поиск, сортировка, установка в один клик
   с обязательными зависимостями (например Fabric API), проверка хешей,
   список установленных, включить/выключить мод, удалить.
6. **Изолированные сборки**: у каждого профиля своя папка (моды, ресурспаки, миры,
   скриншоты), а библиотеки и ассеты общие — ничего не качается дважды.
7. **Скриншоты** (вместо «Друзей» — без своего сервера друзья были бы фейком):
   галерея из всех сборок, просмотр, открыть папку, удалить.
8. **Настройки**: ник, память (ползунок с учётом ОЗУ компьютера), Java (авто/своя),
   папка игры, размер окна/полный экран, что делать с лаунчером после запуска,
   доп. аргументы JVM.
9. **Запуск**: прогресс загрузки по этапам, лог игры, кнопка «Закрыть игру».
10. «Ускорить игру» — баннер на главной ставит Fabric + Sodium в один клик.

## Безопасность
- `contextIsolation`, без `nodeIntegration`, `sandbox`, строгий CSP, свой протокол `app://`.
- Всё сетевое и файловое — только в main-процессе, наружу торчит узкий API через preload.
- Имена файлов от рендерера проверяются (никаких `../`), удаление — только внутри папок лаунчера.
- Загрузки только с доверенных хостов (Mojang, Modrinth CDN, Fabric, Adoptium), с проверкой хеша.
- Внешние ссылки открываются в браузере только по `https://`.

## Дизайн
- Цвета: фон `#0F0809`, панели `#170C0D`/`#201112`, рамки `#3B1517`,
  акцент `#E0262B`, подсветка `#FF4A3D`, «лава» `#FF8A3D`, текст `#F3E9E7`, вторичный `#A88F8C`.
- Шрифты: Russo One (заголовки, блочный, с кириллицей) + Manrope (текст).
- Главная фишка — анимированная пиксельная сцена в баннере (рисуется кодом,
  без чужих картинок): крепость, лава, кровавое солнце, искры. 3 слайда.
  Остальное спокойное и строгое.
- Свой логотип: пиксельная звезда + «ASTRA». Никаких логотипов Minecraft/Mojang.
- Иконки версий — изометрические пиксельные блоки, нарисованные кодом.
- Окно без системной рамки, своя полоса заголовка. Уважение `prefers-reduced-motion`.
- Тексты простые, кнопки называют действие («Играть», «Установить», «Удалить»).
